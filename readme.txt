Exibe um alerta visual, somente informativo, se o título de uma matéria contiver termos definidos pelo administrador.

== Instalação ==

1. Compacte a pasta `aviso-titulo-bloqueado` em um arquivo ZIP.
2. No WordPress, acesse Plugins > Adicionar novo > Enviar plugin e envie o ZIP.
3. Ative o plugin.
4. Acesse Configurações > Aviso no título.
5. Cole a lista recebida, usando uma palavra ou expressão por linha, e salve.

== Comportamento ==

O aviso aparece abaixo do campo de título no editor clássico de posts e páginas. Ele identifica todos os termos encontrados, ignorando maiúsculas/minúsculas e acentos comuns (por exemplo, "educação" e "educacao").

O plugin não altera permissões, não modifica conteúdo e não bloqueia salvar, agendar ou publicar posts.

== Compatibilidade ==

Desenvolvido sem sintaxe moderna de PHP para atender instalações antigas: WordPress 3.0+ e PHP 5.2+.
